# 0003 — Distribution & deployment (closed-source binaries)

- **Status:** Accepted
- **Date:** 2026-10-26

## Context

Spawnt is a closed-source, solo-bootstrapped desktop + CLI product that must ship to Windows, macOS and Linux with zero servers to maintain before the Teams tier.

## Decision

- **Two-repo topology:**
  - `mwahaj36/spawnt` (**private**): source code, tests, fixtures, CI workflows.
  - `mwahaj36/spawnt-releases` (**public**): GitHub Releases hosting compiled binaries, `latest.json` updater manifests, `SHA256SUMS`, install scripts, and public issue tracking.
- **CLI distribution channels:**
  - npm: lightweight JS shim `spawnt` + per-platform binary packages `@spawnt/cli-<platform>`.
  - Homebrew tap (`mwahaj36/homebrew-tap`), Scoop bucket (`mwahaj36/scoop-bucket`), winget, and AUR (`spawnt-bin`).
  - Standalone `.tar.gz`/`.zip` archives + shell/PowerShell installers (`spawntv.vercel.app/install.sh`, `install.ps1`).
- **Tray distribution:** Tauri v2 (`tauri-action`) producing universal `.dmg`, `.msi`/NSIS `.exe`, and `.AppImage`/`.deb`/`.rpm`, updated via Tauri's Ed25519-signed updater manifest.
- **Code signing:**
  - macOS: Apple Developer Program (\$99/yr) starting in M3 (CLI in M1–M2 does not require notarization when installed via npm/Homebrew/curl).
  - Windows: Individual OV code-signing certificate on cloud HSM (~\$100–300/yr) starting in M3; unsigned in M1–M2.
  - Linux: minisign-signed `SHA256SUMS`.
- **Compliance bundle:** every archive/installer includes `EULA.txt` and `THIRD_PARTY_NOTICES.html` (generated by `cargo-about`).
- **Web & licensing:** Cloudflare Pages (`spawntv.vercel.app`) + Cloudflare Worker for Ed25519 license signing on Lemon Squeezy / Paddle webhooks.

## Consequences

- Near-zero recurring monthly cost until M3 signing and M5 Teams.
- Private repo CI minutes are metered (Windows ×2, macOS ×10); CI runs Linux+Windows on PRs, macOS on `main` merges, and full 3-OS release builds on tags.
- Every release channel is automated from a single `vX.Y.Z` git tag push in the private repo.

## Alternatives considered

- **Single public repo:** incompatible with closed source.
- **Self-hosted binary/update servers:** unnecessary bandwidth cost and ops burden vs. public GitHub Releases + Cloudflare R2 mirror.
