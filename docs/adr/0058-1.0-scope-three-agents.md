# 0058 — 1.0 supports exactly Claude Code, Codex and Antigravity

- **Status:** Accepted
- **Date:** 2026-11-13

## Context

ROADMAP_1.0 E4 records Wahaj's final decision (2026-11-13) that 1.0 supports Claude Code, Codex and Antigravity only. Teams, the extra adapters (Cursor, Aider, Cline/Roo; removed earlier on 2026-11-12) and the Gemini CLI adapter were frozen behind off-by-default toggles by ADR 0049. Frozen code still has to be maintained, tested and described, and the surfaces that mention it make claims the product cannot back.

## Decision

1. Delete rather than freeze: the `AgentId::GeminiCli` variant, the Gemini adapter and its fixtures, snapshot and tests, Gemini CLI executable discovery, launch, resume, startup-screen, model-switch and doctor paths, the Gemini CLI model catalog, the `teams_enabled` and `extra_adapters_enabled` feature toggles, and the Gemini CLI entries in console, tray, remote companion and onboarding surfaces. Teams has no code or UI in 1.0.
2. Keep Gemini MODELS used by Antigravity (pricing families, pool names, `GEMINI_HOME` as Antigravity's data root). Keep account metadata sync.
3. Never delete user data. Rows written by removed agents stay in SQLite. `AgentId::parse` returns `None` for them, so typed lists, queues and reports skip them; untyped lists show them as "Unsupported agent". Aggregate token SQL keeps the `gemini-cli` cache-token semantics so historical totals do not change. Stored `FeatureToggles` JSON with the removed keys still loads (unknown keys are ignored).
4. The signed-license `team` tier stays verifiable so licenses already issued keep working; it is treated as Pro and no Teams feature exists. The Supabase Teams tables in `supabase_cloud_sync_v1.sql` are left in history and never dropped by this change.
5. The roadmap item for protocol-mode approvals drops its Gemini CLI part. Removed agents can return after 1.0 through SPEC plus a new ADR.

## Consequences

Smaller surface and no unverifiable claims. Existing installs upgrade without a data migration; old Gemini CLI, Cursor, Aider and Cline history remains on disk but is not shown as a supported agent. ADR 0049 is partly superseded: only the scheduled-message and account-sync toggles remain.

## Alternatives considered

- Keep freezing behind toggles: keeps dead code and misleading docs.
- Migrate or delete old rows: destructive; rejected.
