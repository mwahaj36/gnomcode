# 2026-11-14 WSL console UI

## Goals
ADR 0060 PR 4: "Run in" picker, distro badge, readable long share paths.

## Outcomes
- `GET /api/v1/wsl/distros` for the picker (never boots a distro).
- New-session form: "Run in" select (Windows first, then each distro, stopped ones marked "starts on launch"), Linux folder field with recent folders, remembered per folder, `starting` shown after launch.
- Distro badge (`WSL: <distro>`) on sidebar and Home session rows.
- Resolved share path middle-truncated with a tooltip and a Copy button.
- e2e daemon sets `GNOMCODE_DISABLE_WSL` so tests never read this machine's distros.

## Problems and fixes
None beyond keeping the Playwright daemon hermetic.

## Decisions
Remote launch already accepts a `\\wsl.localhost` folder; a picker in the separate Remote phone app is not built yet.

## Verification
Rust gate, web typecheck, unit tests, console bundle check, full Playwright suite (new `wsl.spec.ts`: picker, WSL row, long path at 1440 and 390 px, light and dark).
