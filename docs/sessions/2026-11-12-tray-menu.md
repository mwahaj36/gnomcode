# 2026-11-12 - Tray menu with limits and sessions overview (overhaul Phase 8)

## Goals
- Replace the static tray right-click menu (Open, Quit) with a native menu that shows sessions needing the user, running sessions and a per-provider limits submenu (plan section 15.2).

## Outcomes
- New pure module `apps/desktop/src/tray-menu.ts`: `formatTrayMenu(overview, sessions, now, options)` returns a data template (labels, enabled flags, submenus and typed actions); `formatTrayTooltip(overview)` returns a tooltip of at most 127 characters. No Electron imports, so both are unit-tested directly.
- `apps/desktop/src/main.ts` maps the template to a native `Menu`, polls the daemon every 30 s, rebuilds only when the serialized template changed and defers a rebuild while the menu is open (`menu-will-show` / `menu-will-close`, with a two-minute safety valve so a missed close event cannot freeze updates).
- `apps/desktop/src/daemon-client.ts` gained `daemonRequest`, an authenticated loopback GET/POST that resolves `null` on any failure.
- Left-click behavior and the existing 5 s badge refresh are unchanged. The badge refresh no longer overwrites the tooltip once limits are known.
- SPEC section 3.13 documents the menu.

## Decisions and deviations
- **Multi-pool headline.** For a provider with more than one pool and at least one exhausted pool the headline reads `N pool(s) out` (matches the mockup `Antigravity    1 pool out`); otherwise it is the Rust `headline_window` formatted like the card summary.
- **Detail wording follows the mockup** (`Weekly: exhausted, back Mon 1:20 PM`, `Session: reset, awaiting reading`); top-level headlines use the short words (`Weekly out`, `Session reset`).
- **Ordering.** Needs-you lists the longest-waiting session first; Running lists the most recent first. `and N more` is a disabled line when a section has more than 3.
- **New session** opens the Sessions view (`#sessions`); the console has no hash that opens the launcher directly, and adding one is outside this phase (desktop-only scope).
- **Open limits** opens `#usage`, as the plan says.
- Reset times are formatted in the local zone from the Rust UTC timestamps; Intl output is assembled by hand because newer ICU inserts a narrow no-break space before AM/PM, which would break the ASCII rule.
- A failed overview request alone shows `Limits unavailable` and keeps sessions; both failing shows `Daemon unavailable`.

## Problems encountered
- `plain()` folded the four spaces between name and headline; the provider label now joins already-plain parts directly.
- `npm run lint` already fails on `main` (empty `catch (_) {}` blocks and a control-character regex in `security.ts`); this change adds no new lint errors.

## Apple HIG review (menus, context menus, writing)
- Submenus stay one level deep; the menu has three groups; labels are short and start with a verb for actions (`Open limits`, `Copy enable command`, `New session`).
- Informational lines are disabled rather than hidden because they are headers and readings, not unavailable commands.
- No color or icons are used; state is stated in words, per the writing guidance on not relying on color alone.
