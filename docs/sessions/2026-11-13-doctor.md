# 2026-11-13 - Diagnostics command and endpoint (`gnomcode doctor`)

## Goals
- Upgrade `gnomcode doctor` and add authenticated `GET /api/v1/doctor` reporting `ok`/`warn`/`fail` checks with one-line fixes across agent CLIs, Claude sign-in expiry, limit sources, Claude integration, daemon reachability, disk free space and keep-awake state.
- Exit non-zero on any `fail` check and never expose credential token values.

## Outcomes
- Added `gnomcode_platform::disk_free_bytes`, `gnomcode_platform::executables::resolve_agent_executable` and `gnomcode_platform::keepawake::is_supported`.
- Added `crates/daemon/src/doctor.rs` with pure `evaluate(DoctorInputs)` and live runners `run_for_daemon` and `run_for_cli`, plus `GET /api/v1/doctor` behind `validate_auth`.
- Updated `gnomcode doctor` (supporting `--json` and existing `--network`) to print `[OK]`/`[WARN]`/`[FAIL]` checks with one-line fixes and exit with status 1 on `fail`.
- Updated `docs/SPEC.md` and `docs/ROADMAP_1.0.md`.

## Problems encountered
- `reqwest` in this workspace does not enable the `query` feature on `RequestBuilder`, so query parameters for `?repo=` are built with `reqwest::Url::parse_with_params`.

## Decisions
- Kept missing optional setup (stopped daemon, missing `.credentials.json`, missing hooks, zero detected CLIs) as `warn` rather than `fail` so offline fresh environments pass smoke diagnostics while broken/expired state (`expired` sign-in, corrupt JSON, unreachable `daemon.json`, `< 100 MB` disk) returns `fail` and exits non-zero.
- When the daemon is running, `gnomcode doctor` queries `GET /api/v1/doctor` so live `keep_awake` holds and in-memory `vendor_limits` issues are included without duplicating daemon state on disk.

## Verification
- Unit tests in `crates/platform` (`disk_free_bytes`, `resolve_agent_executable`) and `crates/daemon` (`doctor::tests::*`, `api::tests::doctor_endpoint_requires_auth_and_returns_checks`), plus `crates/cli/tests/cli_smoke.rs` using temp dirs and env overrides.
- Full Rust gate (`cargo fmt --all`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo test --workspace` with `CARGO_INCREMENTAL=0`, `cargo deny check`).
