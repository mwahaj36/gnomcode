# UI accessibility and usability pass

Started from fresh main at 617e07c, after PR #108. The goal was a product-wide usability and accessibility review, including navigation, feedback and secret visibility.

Used the downloaded Unslop skill, the existing Impeccable guidance and Apple Human Interface Guidelines with the established Spawnt design system. Account password fields and the local desktop pairing token have keyboard-accessible visibility controls. Account request and sign-out failures show actionable feedback, account labels and inputs are more readable, pricing fields retain visible labels, and the account heading identifies the current task. Navigation toggles describe their current action; the desktop rail has a valid tab-list structure and keyboard access, and its subscription action is a real button. Remote dialogs have names, and the phone conversation drawer accepts Escape and restores focus. Search now reports when no conversations match. Trust labels wrap at narrow widths. Contrast and labels identified by accessibility scans were corrected in documentation, Profile and desktop automation.

The desktop browser fixture had drifted from the conversation API; it now supplies the current endpoint, allowing the interaction and view checks to exercise the interface again. Supabase clears the local session even if server-side sign-out fails, so the failure message asks the user to check account status and retry rather than claiming the local session remained active.

Verification: Rust quality gate (format, Clippy, workspace tests, cargo-deny and core purity), web typecheck/tests and production build, desktop browser views in light and dark at desktop and phone widths, keyboard navigation and token visibility, mobile console navigation, authenticated and signed-out automated WCAG A/AA browser scans, and the encrypted Remote browser flow against a local test relay. The public relay could not be reached from this environment. Automated checks and simulated devices do not replace physical-device, platform screen-reader or independent accessibility acceptance.
