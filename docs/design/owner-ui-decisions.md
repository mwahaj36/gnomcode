# Owner UI Decisions

## Owner decisions

- **Canonical Gnomcode colors & CTA roles:** what: Dark surfaces `#070708` (`--sp-bg`), `#0d0d0f` (`--sp-surface`), `#141416` (`--sp-surface-2` / `--sp-surface-raised`), `#18181b` (`--sp-surface-overlay`), `#242428` (`--sp-border`); light surfaces `#f6f7f8` (`--sp-bg`), `#fff` (`--sp-surface`), `#edf0f3` (`--sp-surface-2` / `--sp-surface-raised`), `#d9dfe6` (`--sp-border`), `#525e70` (`--sp-text-3`); primary CTAs use `--sp-cta-bg` (`#f6f7f8` dark / `#252e99` light) with `--sp-cta-text` (`#0c1119` dark / `#fff` light); red (`--sp-danger`: `#ff4d5e` dark / `#d4102e` light) strictly for danger/exhausted | where: `web/app/gnomcode-tokens.css` (`:root`, `:root[data-theme="light"]`, `@media (prefers-color-scheme: light)`) | PR: PR 1
- **Brand-red 53-week Activity heatmap (Home & Usage):** what: Use brand red `--sp-heat-0..4` (`#17171a`, `#4a121b`, `#7d1626`, `#ba1c35`, `#ff2544` dark; `#e4e9ee`, `#fcd1d8`, `#f799a8`, `#ec526b`, `#ff2544` light) on both Home and Usage pages | where: `web/app/gnomcode-tokens.css` (`:root`, `:root[data-theme="light"]`, `@media (prefers-color-scheme: light)`) | PR: PR 1
- **Themed scrollbars everywhere:** what: Thin `6px` scrollbars using `--sp-border-strong` (`#38383e` dark / `#becbd8` light) on `transparent` track in dark and light modes | where: `web/app/gnomcode-console.css` (`:is(.sp-native-console, .sp-console-app, .sp-remote) *::-webkit-scrollbar*`) | PR: PR 1
- **Non-wrapping status chips & subagent pills:** what: Pills never wrap mid-label across lines (`display: inline-flex; white-space: nowrap; flex: none;`) | where: `web/app/gnomcode-console.css` (`:is(.sp-native-console, .sp-console-app, .sp-remote) :is(.sp-badge, .sp-chip, .sp-state-pill, .sp-subagent-pill)`) | PR: PR 1
- **Unified collapsible 268px left sidebar (desktop) + bottom 4-tab bar (mobile):** what: Integrate nav (`Home`, `Chats`, `Usage`, `Settings`) and Conversations (`Search sessions`, `New`, grouped list, `All chats ›`) into one collapsible `268px` left sidebar on desktop (`>= 768px`) instead of a separate 64px rail; move 4-tab nav bar to bottom thumb zone on mobile (`< 768px`) | where: `web/local-console/ConsoleShell.tsx` (`#console-nav-sessions`, `.sp-nav-footer`), `web/local-console/WorkspaceView.tsx` (`createPortal` to `#console-nav-sessions`), `web/app/gnomcode-console.css` (`body.sp-native-console[data-rail="expanded"]`, `@media(max-width:767px)`) | PR: PR 2
- **No selection outline/stripe on active nav tab or active chat row:** what: Use clean `--sp-surface-raised` fill only (no inset border/outline on mouse selection; `:focus-visible` remains keyboard-only) | where: `web/app/gnomcode-console.css` (`body.sp-native-console .sp-console-nav .tab-btn.active`, `:where(.sp-native-console) .ide-session[aria-current="true"]`, `.sp-web-app .sp-console-nav button[aria-current="page"]`) | PR: PR 2
- **Zero horizontal page scroll everywhere:** what: Prevent horizontal page overflow (`overflow-x: hidden` / `min-width: 0`) across Workspace, Home, Usage, All chats, and Settings (only the 53-week heatmap scrolls internally) | where: `web/app/gnomcode-console.css` (`html,body.sp-native-console`, `.sp-console-workspace`, `.sp-console-content`) | PR: PR 2
- **Subagents collapsed by default & capped inline at 5 + dedicated `All chats` pane:** what: Collapse subagents behind `▸ N running · M subagents`, expand inline to at most 5 rows with `View N more in All chats ›`; dedicated full-width `All chats` pane with search, filter chips, `Include subagents` toggle, and token/cost readouts | where: `web/lib/console-presentation.js` (`renderSubagents`), `web/local-console/WorkspaceView.tsx` (`allChatsOpen`, `.sp-all-chats-pane`, `.sp-all-chats-trigger`) | PR: PR 3
- **Single-line padded quick prompts on mobile:** what: Keep quick prompt strip (`Continue`, `Run tests`, `Summarize`, `Customize`) on one scrollable line (`flex-wrap: nowrap; overflow-x: auto`) with `36px` height and `14px` horizontal padding on mobile, never wrapping an orphan `Customize` pill | where: `web/app/gnomcode-console.css` (`@media (max-width:767px)` `.sp-quick-actions`, `.sp-quick-action`) | PR: PR 3
- **IDE-style Provider & Model switcher + Usage popover:** what: Model menu lists all switchable providers (`Antigravity`, `Claude Code`, `Codex`) with `Out` / `% left` badges; clicking `View Usage ›` (or header quota trigger) opens Usage popover showing all providers and their pools | where: `web/local-console/WorkspaceView.tsx` (`providerBadgeLabel`, `.sp-limits-popover-trigger`, `.sp-usage-popover`) | PR: PR 3
- **Home section order & full-width `2fr / 1fr` desktop grid:** what: Full-width `Limits` row at top; below it on desktop (`>= 1024px`), `2fr / 1fr` split with `Activity` (53-week grid) then `Sessions` in left `2/3`, and `Today` (`Tokens today`, `Est. spend today`, `Active sessions`) in right `1/3`; mobile stacks `Limits -> Activity -> Today -> Sessions` | where: `web/local-console/HomeView.tsx` (`.sp-home-react`, `.sp-home-grid`), `web/app/gnomcode-console.css` (`.sp-home-grid`, `@media (min-width:1024px)`) | PR: PR 4
- **Activity grid month labels & mobile right-first scroll:** what: Show month labels (`Nov`–`Nov`) and day labels (`Mon`, `Wed`, `Fri`) on both Home and Usage activity grids, and scroll to the right edge (`scrollLeft = scrollWidth`) first on mobile so recent weeks show first | where: `web/local-console/HomeView.tsx` (`weeks: 53, months: true`), `web/lib/console-presentation.js` (`renderHeatmap`, `updateHeatmap` `scrollLeft = next.scrollWidth`) | PR: PR 4
- **Session token & bar visibility preserved:** what: Keep per-session token readout and mini usage bar on Home `Sessions` rows and token/cost metadata in `All chats` | where: `web/lib/console-presentation.js` (`homeRow` `.sp-session-tokens`, `.sp-session-context`), `web/local-console/WorkspaceView.tsx` (`.sp-all-chat-row`) | PR: PR 4
- **Multi-pool provider card state (Antigravity):** what: Show `Out` only when all pools/windows are exhausted; when some pools are exhausted while others have capacity, show `Low` (amber) with active pool summary (`Gemini Models 13% · 1 pool out`) | where: `crates/daemon/src/api/providers.rs` (`provider_state`, `headline_window`), `docs/SPEC.md` §3.9, `web/lib/console-presentation.js` (`summaryLine`) | PR: PR 4
- **Settings page redesign:** what: Clean single-column grouped sections, unified form controls, and `44px` mobile touch targets | where: not yet implemented | PR: PR 5
