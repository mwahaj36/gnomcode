Local first. Connected when you choose.

Connecting publishes project names, session IDs, agent activity, usage and quotas to your account. This snapshot is not end-to-end encrypted. New snapshots exclude conversation text and titles; older copies may still contain titles. Project names and other metadata can still be sensitive. Remote conversations use a separate encrypted connection.

Snapshots update about once a minute while gnomcode is running. Local monitoring works without an account.
