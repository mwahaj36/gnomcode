Getting started with Gnomcode

Your agents. One workspace.

Launch your coding agents, return to saved conversations and understand your usage from one place.

  1. Prepare an agent and sign in with its provider.
  2. Choose a project folder and launch a session.
  3. Send your first request and follow the work.

Local features are free and do not require a Gnomcode account. You bring your own agent CLI and provider access.

Prepare your coding agent

Install at least one supported official CLI: Claude Code, Codex, Gemini CLI or Antigravity CLI. Open it in your terminal and complete its sign-in or configuration first.

Already using an agent?
The session launcher checks installed CLIs and shows setup guidance. If you just installed one, restart Gnomcode so it can see the updated environment.
Using Cursor, Cline or Roo?
Supported local records can appear in history. These editor agents cannot be launched or controlled here.

Your agent manages its credentials and permissions. Gnomcode does not supply a model subscription or automatically approve agent actions.

Start with a real project

In Workspace, choose New, then select your agent and the folder it should work in. Use the folder button in the desktop app, or enter the folder's full path.

  1. Keep the default model unless you need a specific one.
  2. Select Launch Agent.
  3. Open the session's terminal if the agent asks you to sign in, trust the folder or approve an action.

Choose a folder you are comfortable letting your agent work in. Gnomcode preserves the agent's native permission checks.

Give your agent a first task

Try a focused request in the conversation:

Explain this project's structure and suggest where I should start. Ask before making changes.

Press Enter to send; use Shift + Enter for a new line. Return to saved conversations from the Workspace list. Use the model selector beside the composer to request a supported model or provider change.

Understand your usage
Dashboard, Usage and Limits show recorded activity. Exact, estimated and unknown labels describe the evidence; estimated cost is not your provider's bill.
