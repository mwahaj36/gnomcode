FAQs

        
Extra questions about the how and the why? Reach out on our community channel and we'll happily expand.

      


      

        

          
          

            Daytona provides fast, stateful, and secure sandbox execution infrastructure tailored specifically for autonomous coding agents, LLMs, and evaluation harnesses.
          

        


        

          
          

            Every sandbox operates within strict kernel-level boundaries using gVisor/KVM virtualization, isolated network namespaces, and automatic secret redaction.
          

        


        

          
          

            They provide long-running, stateful compute environments where agents can install packages, run tests, debug compile errors, and verify changes without touching host systems.
          

        


        

          
          

            Use native SDKs for Python, TypeScript, Ruby, Go, and Java, or call the programmatic REST and WebSocket APIs directly from your orchestrator.
          

        


        

          
          

            SOC 2 Type II certified, GDPR compliant, HIPAA ready, with end-to-end encrypted sessions and zero persistence after sandbox deletion.
          

        


        

          
          

            Yes, Daytona offers both a self-hosted open-source core and enterprise private cloud deployments on AWS, GCP, and Azure.
