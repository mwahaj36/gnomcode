# Code of Conduct

We want Gnomcode to be a respectful, harassment-free project for everyone.

Expected: be kind, assume good intent, give and accept constructive feedback, focus on the work.

Not acceptable: harassment, discrimination, personal attacks, doxxing, sexualized content, or publishing private information (including agent logs that contain secrets).

Maintainers may edit, remove or reject contributions and ban participants who violate this code. Report problems privately through GitHub's report feature on the repository, or contact the maintainer on GitHub (mwahaj36). Reports are handled confidentially.

This policy follows the spirit of the Contributor Covenant 2.1.
